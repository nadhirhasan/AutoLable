Auto-label with Claude

Class definitions come from Classes. Claude's boxes are marked Review until you check them. Reviewed images are never overwritten except with “Only the current image”.

Classes

The order is the class id (0, 1, 2…). The SwishStation detector expects ball, made, person, rim, shoot. Renaming, reordering and deleting update every label file; deleting a class deletes its boxes. Definitions are sent to Claude.

Export dataset

Exports 0 images (reviewed + imported). Writes data.yaml + train|valid|test/images|labels for Ultralytics YOLO (yolo26) and _annotations.coco.json per split for RF-DETR. Re-exporting to the same folder replaces the previous export.

Rename project

Renames the project folder. Letters, numbers, - _ .; other characters become _. Re-export after renaming: an old export's data.yaml still points at the old folder.
